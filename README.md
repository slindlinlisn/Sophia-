# Sophia's little world ♡

A pink, dusty-rose, teddy-brown and leopard-print scrapbook website. Built as a static site, so it can be hosted for free with **GitHub Pages**.

## Preview locally
Open `index.html` in a browser. No build step or installation is needed.

## Publish for free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `sophias-little-world`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository's root (not inside another folder).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. GitHub will show your free website address in the Pages section.

## Make it personal
Open `script.js`:
- Edit `quizQuestions` to add your real inside jokes and favourite things.
- Edit `letters` to replace the sample messages with your own words.
- Add or change recipes in the `recipes` list.

## Notes
- This site does not need a paid plan, server, database or API.
- The Google Fonts are loaded online; if unavailable, fallback fonts are used.
- The sample quiz questions and letters are placeholders. Personalize them before sharing.
